One of the decisions that I made while designing the database is that I wanted it to work exclusively with the files given and not create additional files. The strenght of this is that it works on the orgininal data, with one Python script automatically cleaning and creating SQL for one data file. However, this approach comes at the cost of increased SQL runtime during populating the expression data with the use of nested subqueries for the geneInfo table. 

This limitation could be solved I were to create the geneInfo table locally to allow for Python premapping of the genetic information, this would drastically increase run time as this would alleviate the need for the sue of sub-queries in the initial data uplaod.
